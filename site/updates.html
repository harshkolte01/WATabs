How updates work

Until Phase 7 ships in the desktop app, there is no in-app auto-update. Download installers from GitHub Releases manually.

Where binaries live

Signed installers and updater metadata are published to GitHub Releases. This Vercel site does not host update packages or signing keys.

Channels

  • Stable — tags like v1.2.3, marked as the latest release. Default channel for users.
  • Beta — tags like v1.2.3-beta.1, published as GitHub prereleases for early testers.

Trust model

  • OS code signing on Windows (Authenticode) when cert secrets are set
  • macOS Apple signing / notarization is out of scope (unsigned ZIP only)
  • Update payload signatures verified by the app before apply (when feed is live)
  • Electron fuses hardened on packaged builds (DevTools off, etc.)

What an update must never do

Replace only application binaries and resources. Account partitions, metadata, downloads history, and lock verifier stay in userData across upgrades.

Today vs after Phase 7

  • Now: pnpm start and local pnpm package have no auto-update.
  • After Phase 7: packaged apps check the signed feed, download, and prompt to restart — still without touching sessions.
