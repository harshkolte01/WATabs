How updates work

Where binaries live

Signed (or self-signed) installers and updater metadata are published to GitHub Releases. This Vercel site does not host update packages.

Channels

  • Stable — tags like v1.2.3 (latest release). Default in the app.
  • Beta — tags like v1.2.3-beta.1 as GitHub prereleases.

Trust model

  • Windows Authenticode when a cert is configured (self-signed OK for testing)
  • macOS Apple signing / notarization is out of scope
  • Packaged builds harden Electron fuses (DevTools off, etc.)

What an update must never do

Replace only application binaries. Account partitions and settings in userData stay across upgrades.
